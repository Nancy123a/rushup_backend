# README #

Rushup is a cloud-based Android application using AWS. It offers fast delivery, real-time driver tracking on Google Maps, and navigation of past purchases. User information is securely stored with AWS Cognito and IAM. AWS Lambda queries product info from DynamoDB, coordinated by Step Functions for efficient workflow. CloudWatch manages logging and tracks bugs.
